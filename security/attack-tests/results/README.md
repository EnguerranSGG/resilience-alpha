# results/

Sorties CSV des essais Locust (`run-loadtest.sh`). Contenu ignoré par Git.

Une sortie ne devient une **preuve** que si elle provient d'un essai réellement effectué dans le laboratoire, accompagnée de : date et heure, commit testé, configuration (`loadtest.env.used`), matériel, et captures Grafana correspondantes. Ne jamais éditer ni compléter un fichier de résultats à la main.
