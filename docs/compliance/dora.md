# Enjeux DORA (règlement UE 2022/2554)

DORA encadre la résilience opérationnelle numérique du secteur financier :
gouvernance, gestion des risques ICT, tests, incidents majeurs, prestataires
tiers, partage d'information.

Pour le démonstrateur, les analogies utiles sont :

- tests de résilience (ici : Locust borné, pas TIBER) ;
- journalisation des incidents ;
- RTO/RPO documentés ;
- dépendance à des composants open source (équivalent « tiers »).

Ce n'est **pas** un programme de tests avancés au sens DORA.
