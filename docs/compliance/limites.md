# Limites de démonstration et de conformité

Ce prototype **ne démontre pas** :

- une conformité NIS2 ou DORA opposable ;
- un SOC 24/7, un PSSI, un plan de communication de crise ;
- des tests d'intrusion hors labo ;
- une haute disponibilité, des sauvegardes offsite, un PRA de datacenter ;
- la qualité d'un modèle ML industriel (données synthétiques au départ) ;
- la correction d'une compromission (le scénario est un DoS).

Recommandation de conseil (à reformuler après essais) : traiter ce dépôt comme
un **démonstrateur de chaîne**, puis industrialiser métriques, IAM, SAV, PRA
multi-sites et gouvernance des modèles.
