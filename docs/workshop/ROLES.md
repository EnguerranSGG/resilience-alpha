# Rôles des cinq responsables

Une même personne peut aider un autre domaine. Chaque domaine doit avoir un
**responsable nommé** lundi matin.

## P1 — Développement

Application de paiement, PostgreSQL, authentification, frontend, tests métier,
idempotence, transaction de contrôle.

## P2 — Infrastructure

Docker Compose, réseaux, observabilité, Ansible, moteur de remédiation,
passerelle NGINX (avec P4), Grafana.

## P3 — IA / Data

Collecte Prometheus, Isolation Forest, inférence, contrat d'événement, RAG local.
N'a **aucun** droit d'administration sur Docker.

## P4 — Cybersécurité

Scénario Locust borné, WAF, SIEM/Loki, secrets SOPS, exposition réseau,
garde-fous d'attaque.

## P5 — Gouvernance / Intégration

EBIOS, PCA/PRA, NIS2/DORA, coordination, recette, dossier, pitch, Clip Chrono,
checklist d'intégration.
